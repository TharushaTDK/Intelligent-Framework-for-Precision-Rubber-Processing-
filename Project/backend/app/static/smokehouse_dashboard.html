Component 3 — Smart Smokehouse

Backend validation dashboard for layer-wise drying-time and fire-risk prediction

This dashboard is for research-system validation. Temperature and humidity are submitted as raw readings. The backend automatically retrieves historical readings, constructs the finalized 17 ML features and runs both Component 3 models. Current guidance is classifier-derived status guidance only; Add Fire / Hold Fire / Reduce Fire operating rules remain pending domain validation.
