FEATURE SELECTION POLICY
------------------------
- Keep current temperature/humidity and known drying context.
- Keep gap-aware short-term rate features.
- Keep exact 30/60-minute changes because Stage 06 showed recent behavior is useful, especially for fire risk.
- Keep 30/60-minute variability because the two variability scales are not deterministically identical.
- Drop exact lag values because current + change already reconstruct the lag value algebraically.
- Drop raw source change/trend columns because the timestamp-aware engineered features supersede them.
- Drop near-constant availability indicators from the core predictor set.
